pii-guard

AI에 넣기 전에 개인정보와 시크릿을 찾아 가명으로 바꿉니다. 모든 처리는 이 브라우저 안에서만 일어납니다.

⚠ 페이지가 제대로 실행되지 않았습니다. 파일을 더블클릭해서 열면 브라우저가 스크립트를 막습니다. 터미널에서 npm run web을 실행한 뒤 나오는 주소(http://localhost:5173)로 접속하세요.

    탭을 벗어나고 10분이 지나면 입력과 대응표를 자동으로 지웁니다.

    알아 두세요

    • "발견 없음"은 "안전함"이 아닙니다. 규칙에 맞지 않는 개인정보(이름 없이 누군지 알 수 있는 묘사, 영문 주소 등)는 찾지 못합니다.
    • 복사한 내용은 운영체제의 클립보드 기록(Windows의 Win+V 등)에 남을 수 있습니다. 이 부분은 이 페이지가 통제할 수 없습니다.
    • 입력과 대응표는 어디에도 저장하지 않습니다. 탭을 닫으면 사라집니다.
    • PDF·DOCX·사진과 폴더 검사, AI 보조 탐지는 아직 준비 중입니다.
