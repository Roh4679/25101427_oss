# consent-label-app (동의 문구만 있는 앱)

Next.js app router로 만든 스터디 매칭 회원가입 서비스. **흔적 패턴(`trace`)이 의무별로 충분히 좁은지** 확인하는 fixture다.

동의 체크박스에 "개인정보 수집·이용 동의"라는 일반 문구는 있지만, 처리방침 문구("개인정보처리방침")나 그 링크는 어디에도 없다. "개인정보"라는 단어를 흔적으로 잡으면 이 앱이 "확인 필요"로 빠져 CI에서 차단되지 않는다. 차단되어야 정답이다.

## 심은 문제

| # | 문제 | 위치 | 걸려야 하는 의무 |
|---|---|---|---|
| 1 | 개인정보를 받는데 처리방침 페이지·링크·문구가 없음 | `app/`, `app/layout.tsx` 푸터 | `privacy/policy-page` → **차단** (흔적 없음 = 확실한 부재) |
| 2 | 같은 이유로 처리방침 필수 항목 확인 불가 | — | `privacy/policy-contents` → 확인 필요 |

## 일부러 넣은 "통과해야 하는" 요소

- 필수 동의 체크박스 있음, 기본 체크 아님, 선택 동의 없음 → `privacy/consent-checkbox` 통과.
- 수집 항목이 이메일·비밀번호뿐 → `privacy/minimal-collection` 통과.
- 약관 페이지, 명확한 버튼 문구 → `legal/terms-page`, `ux/button-labels` 통과.
- 이미지·분석 툴·해외 서비스 없음 → 관련 의무 N/A.
- 회원가입 폼 아래 "수집 항목·이용 목적" 안내는 처리방침이 아니므로 흔적이 되면 안 된다.
